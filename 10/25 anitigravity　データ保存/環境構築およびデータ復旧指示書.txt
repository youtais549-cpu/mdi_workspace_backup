【データ復旧と環境再構築の 7 つのステップ】
================================================================================

--------------------------------------------------------------------------------
◆ STEP 1: GitHub からバックアップデータをクローン・取得
--------------------------------------------------------------------------------
1. 新しいパソコン（またはLinux環境/WSL）でターミナルを開きます。
2. 以下のコマンドを実行して、GitHub からリポジトリを取得します：
   git clone https://github.com/youtais549-cpu/mdi_workspace_backup.git
   cd mdi_workspace_backup

3. リポジトリ内の "10/25 anitigravity　データ保存" フォルダの中に、
   今回の代替機で作業した全データ・プログラム・最新ルールが完全に保管されています。
   ※前回の壊れる前のデータと混ざらないよう、この独立フォルダに集約されています。

--------------------------------------------------------------------------------
◆ STEP 2: Python (Conda) 環境の復元
--------------------------------------------------------------------------------
第一原理分子動力学・解析に必要な Python 環境（ASE, PyMDI, Matplotlib 等）を復元します。

【方法 A: 設定ファイルから一括復元（推奨）】
   conda env create -f "10/25 anitigravity　データ保存/環境設定・フォント/conda_environment.yml"
   conda activate mdi_env

【方法 B: 既存の Python 環境に必要なパッケージを追加する場合】
   pip install ase pymdi numpy scipy matplotlib

【フォントの配置（日本語グラフの文字化け・豆腐化防止）】
   "10/25 anitigravity　データ保存/環境設定・フォント/" に入っている
   "msmincho.ttc" と "times.ttf" を、スクリプト実行フォルダまたは
   OSのフォントフォルダ（Linux: ~/.fonts/, Windows: C:\Windows\Fonts）に配置してください。

--------------------------------------------------------------------------------
◆ STEP 3: Antigravity IDE へのルール・記憶の復元（最重要！）
--------------------------------------------------------------------------------
新しいパソコンで Antigravity IDE を起動した際、AIエージェントが過去のすべての
指示・物理的前提・計算ノウハウを 100% 覚えている状態にするための手順です。

1. "10/25 anitigravity　データ保存/学習内容と運用ルール/AGENTS.md" を、
   ワークスペースのルートフォルダ（プロジェクトの一番上の階層）に配置（上書き）します。
2. 同様に、"個別運用ルール群/" の中身を ".agents/rules/" フォルダに配置します。
3. "RELAXATION_GRAPH_PROTOCOL.json" をワークスペース直下に配置します。

★効果:
Antigravity IDE は、毎回の会話開始時に `AGENTS.md` を「最優先・絶対遵守ルール」
として自動的に読み込みます。これにより、新しいPCであっても：
・文献値が 3.03 J/m² であること
・粗結合面（1.776 Å）で切断する自然へき開面の物理的前提
・最適化収束基準（`minimize 1.0e-6 1.0e-2 100 150`）
・スラブ計算前の「バルク 1 点 SCF 先行確定」順序
・指示書テキスト経由のグラフ自動保存システム
などを完全に理解した状態で、即座にアシスタントを再開できます。
AIに対して「AGENTS.md を確認して作業を継続して」と一言伝えるだけで完璧です。

--------------------------------------------------------------------------------
◆ STEP 4: Google Colab (Tesla T4 GPU) & SSH 接続の復旧
--------------------------------------------------------------------------------
1. SSH秘密鍵の配置:
   お使いの SSH 秘密鍵（id_ed25519）を、新しいPCの `~/.ssh/id_ed25519` に配置し、
   アクセス権限を制限します：
   chmod 600 ~/.ssh/id_ed25519

2. SSH設定（`~/.ssh/config`）の作成:
   "環境設定・フォント/ssh_config_backup.txt" を参考に、以下のように設定します：
   Host colab
       HostName 0.tcp.ap.ngrok.io
       User root
       Port <その日のngrokポート番号>
       StrictHostKeyChecking no
       UserKnownHostsFile /dev/null
       IdentityFile ~/.ssh/id_ed25519
       LogLevel ERROR

3. Google Colab ノートブックを起動し、ngrok のポート番号を確認して config の Port を
   書き換えるだけで、ターミナルから `ssh colab` でワンタッチ接続できます。
   ※Colab 側には `/content/bin/pw.x` および `/content/bin/lmp`、NVHPC 24.7 が配備済みです。

--------------------------------------------------------------------------------
◆ STEP 5: Google Drive（永続バックアップ）との連携
--------------------------------------------------------------------------------
すべての計算データは、Google Drive（`G:\マイドライブ\MD_backup\` または

--------------------------------------------------------------------------------
◆ STEP 6: 今後新しい計算を行う際の標準パイプライン
--------------------------------------------------------------------------------
新環境で次の計算（他の周期数、別の方位、300 K AIMD など）を開始する際は、
確立された以下の標準手順に従ってください：

① スラブモデル生成:
   ASE の `surface(bulk, indices=(1, 0, 0), layers=2*N)` を使用し、
   最外層が粗結合面（1.776 Å 切断、密結合保持）であることを自動検証する。

② 真のバルクモデル 1 点 SCF 先行確定（必須順序）:
   スラブ構造緩和を開始する前に、必ず同原子数のバルクモデル（真空 0 Å）で
   QE 1 点 SCF 計算を行い、全エネルギー $E_{\text{bulk}}$（約 -443.49 eV/atom）を
   確定・記録する。

③ スラブ構造緩和の実行:
   入力スクリプト `in.lammps` の収束条件には、実証済みの標準規格を使用：
   `minimize 1.0e-6 1.0e-2 100 150`
   （エネルギー精度を保ったまま、30分程度で確実に自動自然収束します）

④ 3種推移グラフの自動生成:
   計算スクリプト終了時に `python3 auto_generate_progression_graphs.py` が自動実行され、
   全エネルギー推移、作用力推移、SCF補正値推移グラフが Word 最適化サイズ（8cm×6.2cm）で
   計算フォルダおよび Google Drive に自動ダイレクト保存されます。

⑤ 表面破壊エネルギー $\gamma$ の算出と台帳更新:
   `python3 modular_aimd_framework/parameters_variable/calc_surface_energy.py --auto ...`
   を実行し、`surface_energy_results.csv` および `SURFACE_ENERGY_RESULTS.md` を更新。

--------------------------------------------------------------------------------
