1. 表面破壊エネルギー（Surface Fracture Energy: γ）の定義
--------------------------------------------------------------------------------
結晶をある結晶面に沿ってへき開（切断）し、断面積 A のき裂を進展させると、上下（表裏）に合計 2A の新しい自由表面が生成される。
温度 T = 0 K における表面破壊エネルギー γ [J/m²] は、同一原子数 N を持つ緩和後スラブ全エネルギー E_slab(N) と真のバルク全エネルギー E_bulk(N) の差（過剰エネルギー ΔE）として次式で定義される：

  ΔE [eV] = E_slab(N) - E_bulk(N)
  γ [J/m²] = (ΔE / 2A) × 16.021766

  ・等原子数の原則（「同じ大きさのケーキの原則」）:
    スラブモデルとバルク基準モデルは、必ず「完全に同一の原子数 N（かつ同一の化学量論比 Si:C = 1:1）」で比較しなければならない。
  ・分母が 2A である理由:
    断面積 A の結晶面を 1 箇所切断すると、上面（面積 A）と下面（面積 A）の 2 つの表面が同時に生成されるため、生成表面積の総和は 2A となる。
  ・単位換算係数:
    1 eV/Å² = 1.6021766×10^-19 J / 1.0×10^-20 m² = 16.021766 J/m²
  ・3×3 面内スーパーセル（2H-SiC {10-10} 面）の定数:
    Lx = 3 × a = 3 × 3.0760 Å = 9.2280 Å
    Ly = 3 × c = 3 × 5.0480 Å = 15.1440 Å
    片面断面積 A = Lx × Ly = 139.748832 Å²
    全破面面積 2A = 279.497664 Å²
    実効分母 (2A / 16.021766) = 17.44487243166577 [eV / (J/m²)]
    すなわち γ [J/m²] = ΔE [eV] / 17.44487243166577

2. 材料（2H-SiC）および結晶面（{10-10} m面）の選定理由
--------------------------------------------------------------------------------
  ・2H-SiC（ウルツ鉱型構造）を選ぶ理由:
    (1) SiC ポリタイプ（2H, 4H, 6H, 3C 等）の中で c 軸方向の積層周期が最小（1周期 = 2分子層 AB積層）であり、第一原理計算（DFT/AIMD）の単位胞サイズと計算コストを最小化できるため。
    (2) Inomata & Inoue (1970) により、1400℃ 以下の低温領域（室温〜30℃を含む）における熱力学的安定相として確立されているため。
  ・{10-10} 柱面（m面）を選ぶ理由:
    (1) 非極性面（Tasker 分類 Type I）: 各原子層内に Si と C が 1:1 の等モル比で存在し、表面垂直方向（Z軸）の電気双極子モーメントが厳密にゼロとなる。これにより、(0001) 極性面のような真空層内の人工的な静電ポテンシャル発散（双極子補正や水素終端が必須となる問題）が生じない。
    (2) セル面積の最小性: 同じ非極性面である {11-20} a面（面内周期 √3a × c）に比べ、{10-10} m面は面内周期が a × c と小さく、同一スーパーセル倍率で最小の原子数で計算可能。
    (3) 先行研究とのベンチマーク性: Rauls et al., Solid State Commun. 111, 459-464 (1999) の理論値・実測値と直接比較検証が可能。

3. 【最重要】自然へき開面（粗結合面切断）の物理的前提とモデル構築統一規約
--------------------------------------------------------------------------------
  ・2H-SiC {10-10} 面の層構造:
    Z軸（法線方向）に沿って、1周期（長さ √3/2 × a ≈ 2.663894 Å）あたり 2 つの原子層が存在し、層間距離は以下の 2 種類が交互に現れる：
    (a) 密結合層間（Dense bond）: dz ≈ 0.8881 Å（強固な Si-C ダイマー結合ペア）
    (b) 粗結合層間（Sparse bond）: dz ≈ 1.7758 Å（結合が疎で弱い自然へき開面）
  ・脆性破壊・き裂進展の絶対前提:
    き裂は必ずエネルギー最小となる「粗結合面（dz ≈ 1.7758 Å）」を選択して進展する。
    したがって、スラブモデルの切断面（上下の真空層と接する境界）は、必ず「1.7758 Å の粗結合面を切断した位置（＝スラブ内部の両端が 0.8881 Å の密結合ペアを保持した状態）」でなければならない。
    誤って 0.8881 Å の強結合ペアを引きちぎる位置で切断すると、表面破壊エネルギーが γ ≈ 10.64 J/m²（正常値の約 4.3 倍）という非物理的な異常値となるため、強結合面切断は【絶対禁止】とする。
  ・周期数拡張時の ASE surface 統一生成ルール:
    2周期 → 4周期 → 6周期 → 8周期へとモデルを拡張する際は、手動の座標ループスクリプトを一切使わず、必ず以下の ASE 標準関数で統一生成すること：
      from ase.build import surface
      slab_unit = surface(bulk_cif, indices=(1, 0, 0), layers=N_periods, vacuum=None)
      slab_3x3 = slab_unit * (3, 3, 1)
    ※ 2H-SiC.cif に対して indices=(1,0,0), layers=N_periods を指定すると、1 period = 2 原子層（3×3 で 36 原子/周期）として、全 2×N_periods 層（36×N_periods 原子）の自然へき開スラブが生成される。
  ・生成直後の必須プロファイル検証:
    Z座標のユニーク値 z_unique から隣接層間距離 diffs = np.diff(z_unique) を計算し、
      [0.888, 1.776, 0.888, 1.776, ..., 0.888]
    のように「最初と最後が 0.888 Å（密結合保持）であり、外側の真空境界が 1.776 Å（粗結合切断）であること」を必ず計算開始前に自動検証すること。
  ・真のバルクモデル（真空層 0 Å）の正確な Z 軸周期長 Lz:
    N 周期の真のバルクモデルのセル長 Lz は、丸めた層間距離（1.7758 等）を足し合わせるのではなく、必ず結晶学的な厳密式：
      Lz_bulk = N_periods * (np.sqrt(3.0) / 2.0) * a   (a = 3.0760 Å)
    によって算出すること（丸め誤差 0.0002 Å による周期境界の歪みを防止するため）。
    - 2周期 (72原子)  : Lz_bulk = 5.327788 Å
    - 4周期 (144原子) : Lz_bulk = 10.655577 Å
    - 6周期 (216原子) : Lz_bulk = 15.983365 Å
    - 8周期 (288原子) : Lz_bulk = 21.311153 Å

【ルール1】計算結果の上書き防止・個別アーカイブ・バルク1点SCF先行確定

  2. 条件変更時の新規独立ディレクトリ作成:

  3. スラブ緩和前の「バルク 1 点 SCF 先行確定」プロトコル（必須順序）:
     新しい周期数（原子数 N）でスラブ構造緩和を開始する前に、必ず同一原子数 N の真のバルクモデル（真空層 0 Å）の Quantum ESPRESSO 1点 SCF 計算を先行実施する。
     ・1原子あたりのバルクエネルギーが約 -443.493〜-443.495 eV/atom であることを検証する。
     ・確定した E_bulk を `fracture_metadata.json` に記録してからスラブ緩和を開始する。
  4. 総合データベースへの随時記録:
     計算完了時は必ず `SURFACE_ENERGY_RESULTS.md` および `surface_energy_results.csv` に解析条件と E_slab, E_bulk, ΔE, γ を追記する。

【ルール2】元素番号（Type 1 = C, Type 2 = Si）と Winmostar 可視化整合性
--------------------------------------------------------------------------------
  1. 元素番号の厳格統一:
     ASE の `write_lammps_data(..., atom_style='atomic', masses=True)` は元素記号のアルファベット昇順で Type 番号を割り当てる。したがって全ファイル・全スクリプトで以下を厳守する：
       ・Type 1 = C  (質量 12.011)
       ・Type 2 = Si (質量 28.085)
     LAMMPS 入力 (`in.lammps`) でも必ず：
       mass 1 12.011
       mass 2 28.085
       fix 1 all mdi/qm elements C Si
     MDI エンジン (`qe_mdi_engine_*.py`) でも必ず：
       type_to_symbol = {1: 'C', 2: 'Si'}
     ※ これを逆にすると C と Si の擬ポテンシャルと質量が入れ替わり計算が完全に破綻する。
  2. XYZ アニメーション変換 (`make_xyz.py`) の必須ソート:
     `dump.lammpstrj` を Winmostar 用 `md_animation.xyz` に変換する際は、各フレーム内で必ず原子 ID (`aid`) の昇順にソートしてから書き出すこと（未ソートだとアニメーション再生時に原子がフレームごとに入れ替わる）。

【ルール3】プロセス管理と MDI + ASE の DummyMPI 必須化
--------------------------------------------------------------------------------
  1. `killall python3` の絶対禁止:
     Colab 環境や統合開発環境で `killall -9 python3` を実行すると、Jupyter カーネルやバックグラウンド管理プロセスまで強制終了して切断を引き起こすため禁止。
     計算停止時は必ず `killall -9 pw.x lmp` または `pkill -f qe_mdi_engine` を用いること。
  2. ASE + MDI 連携時の `DummyMPI` 強制適用（SIGABRT クラッシュ防止）:
     Python で `import mdi` を行うと内部で `mpi4py` がロードされる。その後 ASE が `sys.modules` 内の `mpi4py` を検知すると、MPI 初期化前に `MPI_Comm_size` を呼んで SIGABRT クラッシュする。
     そのため、MDI エンジンスクリプト冒頭では必ず以下を記述すること：
       import ase.parallel
       ase.parallel.world = ase.parallel.DummyMPI()
  3. MDI ノード登録:
     MDI 1.4+ ではコマンド登録前に必ず `mdi.MDI_Register_Node("@DEFAULT")` を呼び出すこと。

【ルール4】0 K 構造緩和（minimize）と 300 K 有限温度 AIMD（NVT）の役割分担
--------------------------------------------------------------------------------
  1. 表面破壊エネルギー γ の算出は必ず「0 K 共役勾配法（CG法 `minimize`）」で行う:
     γ = ΔE / 2A は T = 0 K 基底状態のポテンシャルエネルギー差として定義される。熱振動エネルギー (3/2 N k_B T) やエントロピー項を混入させないこと。
  2. 300 K 有限温度 AIMD の標準設定:
     表面再構成の熱的安定性やき裂進展を評価する有限温度 AIMD は、必ず「0 K 緩和済み構造 (`*_relaxed.data`)」を初期構造とし、以下の条件で実行する：
       ・時間刻み `timestep 0.001` (1.0 fs: SiC 最速光学フォノン周期 ~33 fs の 1/30 以下)
       ・熱浴 `fix nvt all nvt temp 300.0 300.0 0.1` (Tdamp = 0.1 ps = 100 fs)
       ・重心ドリフト防止 `fix mom all momentum 50 linear 1 1 1`
       ・標準ステップ数: 1,000 steps (1.0 ps: 前半 0.5 ps 熱平衡化、後半 0.5 ps サンプリング)

【ルール6】真空層厚さ依存性と DFT ノイズフロアによる早期完了判定
--------------------------------------------------------------------------------
  1. 臨界真空層厚さ（2H-SiC {10-10} 面）:
     ・10.0 Å（合計真空 20 Å）: γ = 2.4488 J/m²
     ・5.0 Å （合計真空 10 Å）: γ = 2.4485 J/m²（差 0.0003 J/m²、完全遮断）
     ・2.5 Å （合計真空 5 Å） : γ = 2.4703〜2.4709 J/m²（差 +0.022 J/m²、隣接スラブ間相互作用を検知）
     結論：相互作用遮断の臨界真空層厚さは「2.5 Å 〜 5.0 Å」であり、周期数拡張モデル（4・6・8周期）では計算効率と遮断精度を両立する「片側 5.0 Å（合計 10.0 Å）」を標準採用する。
  2. DFT 数値ノイズフロアと早期完了判定基準:
     Quantum ESPRESSO の SCF 収束閾値 `conv_thr = 1.0e-5 Ry` において、Hellmann-Feynman 力の数値ノイズ限界（フロア）は ~0.0002〜0.0003 Ry/au（≈ 0.005〜0.008 eV/Å）となる。
     そのため、旧設定 `ftol = 1.0e-3 eV/Å` では物理的に緩和が完了していても永遠に停止しない場合がある。
     ① 全エネルギーが小数第 4 位まで固定（または連続 3〜5 ステップで ΔE < 0.1 eV）
     ② 原子最大変位量 Δr_max <= 10^-6 Å（完全静止）
     ③ Total force が停滞
     の 3 条件を満たした場合は、構造緩和 100% 完了と判定する。

【ルール9】全規模スラブ共通の最適化収束条件標準（minimize 1.0e-6 1.0e-2 100 150）
--------------------------------------------------------------------------------
  ・2周期・4周期・6周期・8周期を含むすべてのスラブ構造緩和計算において、LAMMPS の `minimize` コマンドは以下を恒久標準とする：
      minimize 1.0e-6 1.0e-2 100 150
    - `etol = 1.0e-6` : 相対エネルギー変化 <= 10^-6 でのエネルギー底打ち収束判定
    - `ftol = 1.0e-2` : 最大原子作用力 <= 0.01 eV/Å（DFT ノイズフロア ~0.006 eV/Å の直上）
    - `maxiter = 100` : 最大 CG 反復回数
    - `maxeval = 150` : 最大 SCF 力評価回数
